# 产品范围：电脑版与网页版

自 2026-11-13 范围更正起，本项目只维护以下两端：

| 产品 | 入口与实现 | 交付方式 |
| --- | --- | --- |
| Windows 电脑版 | `apps/app-shell`；Electron + 本地 JS 解析器 | Windows 安装版、便携版、自动更新文件 |
| PHP 网页版 | `public`、`app`、`config` | PHP 服务部署；浏览器访问；可使用 Docker 部署 |

手机浏览器响应式布局、PWA 安装入口均属于网页版。HTTP API 是网页版服务的一部分，不是独立客户端。当前不制作 Android APK、iOS App 或其他独立移动版本。

## 核对发现与处理

更正前的仓库实际存在 `apps/mobile` Capacitor/Android 工程，并有 Android 构建及可选签名发布任务。历史 GitHub Releases v1.1.2—v1.1.7 附带过测试签名 APK；本地也曾生成 Debug APK。这些文件确实存在，并不符合本次明确的两端范围。

已从当前代码和本地项目移除：

- 独立移动工程及其依赖、缓存、构建输出与本地 APK；检查时该目录没有 keystore、签名参数或本机 env 配置。
- 仅供该工程使用的 `packages/update-checker`、移动工作流与浏览器夹具测试。
- Android CI、签名发布任务、SDK/JDK 配置依赖、版本号同步要求和移动图标生成。
- 仅用于旧移动图标的三个 SVG 资源；电脑版品牌原图、图标与网页版 PWA 图标继续保留。
- 含旧 Android 下载宣传的 Release 截图，README 改为链接当前 Windows 发布页。

网页更新接口排除 APK/AAB/IPA 附件；`android_asset` 作为旧 API 兼容字段固定返回 null，并标记为废弃。新的缓存键避免复用更正前的移动端推荐结果。

上传检查限制 `apps` 下只能包含 `app-shell`，同时阻止独立原生移动工程重新进入当前仓库。
