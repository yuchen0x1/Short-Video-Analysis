## 功能差距与吸收

| 维度 | 当前与同类的差距 | 决策 |
| --- | --- | --- |
| Windows 更新 | 过去自动下载、退出即可安装。electron-builder 支持签名发布者校验，GitHub 不可变 Release 可提供来源证明。 | 新版给出版本、大小、摘要与稍后处理。签名配置齐全的安装版经确认下载并重启，普通安装包与便携版使用官方发布页。 |
| PWA | 过去缓存立即接管。Workbox 的等待策略支持用户选择时机。 | 用户确认后激活并刷新当前页面，恢复输入草稿。 |
| 解析与工作台 | yt-dlp 站点广度、MeTube 后端队列与 gallery-dl 跨目录维护成本高。 | 优先维护 PHP/JS 契约与公开样本，继续使用现有浏览器历史和本地批量架构。 |
| 竞品 UI | cobalt 突出粘贴，Parabolic 强化桌面任务反馈，MediaGo 拆分下载与界面。 | 使用已有品牌布局，让更新状态与解析工作区分开，保留窄屏与键盘操作。 |
| 发布与维护 | 原工作流缺少完整测试前置条件、包内验证与依赖维护。 | 引入按生态维护、发布后元数据校验、公开归档和只读构建权限。 |

Free Download Manager 的下载队列及续传可用作商业产品对照。其专有素材及实现未使用。研究依据见 [产品官网](https://www.freedownloadmanager.org/)。

近期观察 Electron 45、electron-updater 6.8.12、Workbox 7.4.1 和 hls.js 1.7.4；可先试验再决定引入。当前改进只借鉴工程做法，未复制第三方代码，NOASSERTION 项在实际引入前须阅读许可证与构建选项。大版本前更新深度调研，日常维护按周核对发布和依赖状态。平台判断见 [平台评估](ecosystem-baseline.md)。
